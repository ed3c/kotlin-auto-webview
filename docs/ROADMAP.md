# Roadmap

## Phase 1 — Observer (current)

- Cross-platform WebView shell
- DOM observer and sanitized page context
- L1 deterministic cache
- Projection overlay and context rail
- MCP resources/tools
- Capability and dispatcher state machines

## Phase 2 — Toolmaker

- SQLDelight cache and append-only audit store
- Android/iOS native capability adapters through expect/actual
- Browser action executor using accessibility-first locators
- Permission-to-tool dynamic registration
- Play Integrity and App Attest evidence

## Phase 3 — Orchestrator

- Authenticated OpenClaw L2 WebSocket/Streamable HTTP transport
- P2P/private-edge pairing and key rotation
- Cross-tab/workspace context
- Deep-link and intent tools
- Local embedding/SLM routing with measured battery, memory, and latency budgets
- Reproducible store release pipeline and privacy dashboard
